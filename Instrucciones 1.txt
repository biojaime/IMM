PROYECTO: Sistema Escolar Firebase

OBJETIVO:
Actualizar docente-dashboard.html para convertirlo en un panel completo de gestión académica.

REQUISITOS:

1. DATOS DEL DOCENTE
Al iniciar sesión obtener desde Firebase:

- Nombre completo
- Correo
- Rol
  - Docente
  - Docente Tutor
  - Administrador

Mostrar:

Hola, [Nombre Completo]
Correo: [correo]
Estatus: [rol]

No mostrar únicamente "Hola Docente".

----------------------------------------

2. CLASES ASIGNADAS

Leer automáticamente el arreglo "Clases" del documento del docente en Firebase.

Ejemplo:

Clases:
- Biología (1°)
- Informática I (1°)
- Informática II (2°)

Crear tarjetas dinámicas para cada clase.

----------------------------------------

3. PLANEACIÓN DE PARCIALES

Para cada clase permitir:

+ Crear Parcial
+ Editar Parcial
+ Eliminar Parcial
+ Consultar Parcial

Estructura:

Clase
 └── Parcial 1
      ├── Examen 30%
      ├── Tareas 20%
      ├── Proyecto 30%
      └── Participación 20%

Validaciones:

- La suma debe ser exactamente 100%.
- No permitir guardar si excede o falta porcentaje.
- Mostrar barra visual del porcentaje acumulado.

----------------------------------------

4. BANCO DE CRITERIOS

Permitir crear criterios personalizados:

Ejemplos:

- Examen
- Proyecto
- Práctica
- Tarea
- Investigación
- Participación
- Exposición
- Laboratorio

El docente puede:

+ Crear
+ Editar
+ Eliminar

Guardar en Firebase.

----------------------------------------

5. GESTIÓN DE TAREAS

Por cada criterio tipo "Tarea":

Mostrar:

Tienes X tareas registradas.

Permitir:

+ Nueva tarea
+ Editar tarea
+ Eliminar tarea

Campos:

- Nombre
- Descripción
- Fecha
- Valor

----------------------------------------

6. CAPTURA DE CALIFICACIONES

Seleccionar:

Clase
→ Parcial
→ Criterio

Mostrar lista de alumnos.

Registrar:

Calificación
Observaciones

Guardar automáticamente en Firebase.

----------------------------------------

7. COMENTARIOS POR ALUMNO

Cada parcial debe incluir:

Comentarios Docente

Ejemplos:

"Excelente participación."
"Necesita mejorar hábitos de estudio."

Permitir:

+ Agregar
+ Editar
+ Eliminar

Guardar en Firebase.

----------------------------------------

8. CONSULTA DE ALUMNOS

Botón:

[Consultar Alumno]

Funciones:

Buscar por:

- Matrícula
- Nombre

Mostrar:

- Nombre
- Matrícula
- Grado
- Grupo
- Calificaciones
- Promedio
- Comentarios

----------------------------------------

Usuarios

Diseño moderno tipo dashboard.

Panel izquierdo:
- Inicio

- Reportes

Panel principal dinámico.

Responsive para PC y móvil.
